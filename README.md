# ComfyUI-Goudan-AutoQueue

点一次运行就自动排完整批任务的几组 ComfyUI 节点：

- **提示词循环（自动计条数 + 自动排队）** `PromptCycleAutoQueue`
  连到 Impact Pack 的 String Selector（多行模式），自动数出提示词条数（以单独一行 `#` 分隔），只填轮数，点一次运行就把 条数 × 轮数 次全部排进队列，按顺序轮换，每次重新随机种子。
  - 「全局触发词」（可空）：填了会自动加在每一段提示词最前面（如 LoRA 触发词，中文用“，”分隔，英文用“, ”），在随机变量展开之前加，最终的文本编码和「本次实际提示词」里都有；已经以它开头的段不会重复加。
  - 在界面上点运行时会先弹确认框：本次将运行多少次（非空段数 × 轮数；不分段 = 轮数），取消就不排队。API 调用和自动排出的副本不弹。1.2.8 起按实际会跑的流程算：提示词循环被开关切掉时（例如工作流里的「只放大」模式），不再按段数 × 轮数算——读单张图片不弹框，读文件夹时提示将逐张处理该文件夹。计数按导出的执行图来算，工作流里的节点打包成子图（subgraph）后照样准确。
- 还原记录（默认关）：在保存节点上把「还原记录」开关打开后，每保存一张图（二采 / USD / SeedVR2 / 只放大），就在日期文件夹里的「还原记录.csv」追加一行（UTF-8 BOM，Excel 直接打开；只放大时在 原目录/SeedVR2/ 里）。第一列是文件名（如 usd/01_Krea2-USD_00001_.jpg），按文件名搜就能查到：时间、段/轮、实际提示词（随机展开和触发词之后）、种子、模型、LoRA（只记开着的）、每一步采样设置、缩放等设置（1.2.8 起也记 TE-Speed-VOSR2 放大和 KJNodes 颜色匹配的参数，只在那一步开着时记）、尺寸、源文件。只预览不保存的图不记；开关关着时什么都不写（旧工作流没有这个开关，加载后也是关）。实际提示词来自保存节点的可选输入「实际提示词」（示例工作流已连好）；其余从正在执行的工作流里自动读取（子图里的节点也能读到，标题照常显示），开关关掉的步骤不会记进去。API 提交时 rgthree 种子是 -1 的会先换成具体数字，保证记下的就是实际种子。
- **文件名/文件夹（自动）** `PromptCycleFilenames`
  「序号」「条数」连到提示词循环，一个节点直接输出三个保存路径前缀，分别连三个保存节点（「保存图像」或「保存图像（按输出设置）」）的文件名前缀：`日期/01_Krea2-2ST`、`日期/01_Krea2-USD`、`日期/seedvr/01_seedvr2_after`。编号默认两位（01、02…），超过 99 条自动变成三位。后缀和放大子文件夹名都可以在节点上改。
  「日期」默认 `%date:yyyy-MM-dd%`，在点运行那一刻确定，整批自动排队的副本都用同一个日期，跑过零点也不会分到两个文件夹；也可以直接写固定文字当文件夹名。
- **SeedVR2 按路径读图（逐张，自动排队）** `SeedVR2DirLoad` + **SeedVR2 保存到原目录/SeedVR2** `SeedVR2DirSave`
  粘贴任意文件夹或单张图片路径，逐张放大，结果存到 `<原目录>/SeedVR2/`，保留原文件名并加后缀；已放大的自动跳过，可断点续跑。1.2.8 起保存节点有「图像」输出（存完才输出），可以用来让后面的步骤等它存完再跑。
  - 1.2.0 起节点上多了 **「选择文件夹…」「选择图片…」** 两个按钮：点一下，运行 ComfyUI 的这台电脑会弹出系统自带的选择窗口，选好后路径自动填进「路径」框；点取消什么都不改。窗口从「路径」框里当前的文件夹打开，中文路径没问题。
  - Windows：1.2.5 起直接在 ComfyUI 里调用系统自带的选择窗口（新式文件夹/图片选择窗口，老系统自动退回旧式窗口），不再启动 PowerShell，点按钮立刻弹出，也不需要 tkinter（秋叶整合包这类嵌入式 Python 也能用）。macOS / Linux 暂不支持弹窗，按钮会提示改成粘贴路径。
  - 选择窗口是在运行 ComfyUI 的那台电脑上弹出的，所以只有浏览器和 ComfyUI 在同一台电脑上时才有用；从别的电脑访问时按钮会提示改成粘贴。窗口可能被浏览器挡住，看任务栏。同一时间只开一个窗口。
  - 照样可以直接粘贴路径（带不带引号都行），打不开窗口时右上角也会这样提示。
- **缩放设置** `GoudanScaleSettings`（1.1.0 新增）
  - 「模式」选 **倍数** 或 **长边**，用不到的那一项会自动变灰。
  - **倍数**：默认 1.5，最小 1。1 倍就是同尺寸只做修复。最终尺寸 = 原图 × 倍数（四舍五入）。
  - **长边像素**：默认 3840，按原图比例缩放，最终长边正好等于这个数，短边四舍五入。
  - 目标比原图小的时候，SeedVR2 按 1 倍只做修复，然后用 lanczos 缩小到目标尺寸。
  - 打开「缩小时跳过SeedVR2（只缩放）」后，需要缩小的图完全不跑 SeedVR2，只做 lanczos 缩小，很快。放大的图不受这个开关影响。
  - SeedVR2 处理尺寸会向上对齐到 8 的倍数，最后再精确缩放到目标尺寸，所以输出尺寸是准确的。
- **输出设置** `GoudanOutputSettings`（1.1.0 新增）
  - 「格式」可选 jpg / png / webp，默认 jpg。
  - 「质量」1–100，默认 95，对 jpg 和 webp 有效。png 是无损的，这一项会变灰。
  - jpg 不支持透明，透明部分会铺成白底。png 和 webp 会保留透明。
  - 「保留元数据」默认关：
    - 关：不写 ComfyUI 的工作流和提示词，也不带原图的 EXIF、GPS、XMP，不会泄露位置或相机信息。只有原图用的是 sRGB 以外的色彩配置（比如 Adobe RGB）时才保留它的 ICC，否则颜色会变。
    - 开：写入 ComfyUI 的工作流，图片拖回 ComfyUI 就能打开。png 写在文本块里，jpg 和 webp 按 ComfyUI 的方式写在 EXIF 里。同时保留原图的 EXIF（拍摄时间、GPS 等）和 ICC。方向统一改成 1，因为像素已经转正。
  - 没连「输出设置」的旧工作流照旧保存为无元数据的 png。
- **保存图像（按输出设置）** `GoudanSaveImage`（1.2.0 新增）
  - 用法和 ComfyUI 自带的「保存图像」一样：存到 ComfyUI 的 output 文件夹，文件名前缀可以带子文件夹（比如 `日期/01_Krea2-2ST`），自动加 `_00001_` 编号，节点上显示预览，图像原样输出（可以接图像对比）。
  - 区别是格式/质量/元数据按「输出设置」：连上一个「输出设置」就能存 jpg / png / webp；一个「输出设置」可以同时连好几个保存节点。
  - 「保留元数据」开时写入 ComfyUI 的提示词和工作流（png 写文本块，jpg / webp 写 EXIF）。jpg 的 EXIF 最多 64KB，工作流太大时 jpg 只写提示词（控制台会提示），想把图拖回 ComfyUI 打开工作流就用 png 或 webp。
  - 不连「输出设置」时和自带保存图像完全一样：png、写入工作流。前缀里可以写 `%date:yyyy-MM-dd%`。
- **分段接力排队（MiniMax H3 长视频）** `GoudanSegmentRelay`（1.2.9 新增）
  - 配合 ClipStream 的「读取片段 / 保存片段」节点做长视频：点一次运行，按「轮 → 段」的顺序排好所有任务（例如 3 轮 × 4 段 = 12 个），每段接着上一段的结尾生成。
  - 「分段提示词」一行一段；「段数」填 0 表示按行数算。输出「项目名」连读取片段和保存片段的 project_name，「本段提示词」连生成节点和保存片段的 prompt。
  - 每轮用一个新的项目名（基名_r01_时间），所以每轮是一条独立的长视频；第 1 段自动改成「全新开始」，后面的段自动改成「接续」，读取的片段固定为最新的那个。
  - 「种子」可选每轮随机 / 每轮递增 / 不改；同一轮的各段用同一个种子。
  - 每段开跑前会检查上一段确实存好了：数量不对就报错（中文说明应该有几段、实际几段），并把本轮后面还没跑的段从队列里撤掉，其他轮不受影响。
  - 点运行时的确认框会显示「分段接力：本次将运行 N 个任务」。
- **SeedVR2 前缩放** `GoudanScalePrepare` 和 **最终尺寸** `GoudanScaleFinish`
  - 处理区内部用的两个节点，按「缩放设置」工作，平时不用动。

## 安装
ComfyUI Manager → Install via Git URL，填 `https://github.com/steamwood/ComfyUI-Goudan-AutoQueue.git`；或手动：

```
cd ComfyUI/custom_nodes
git clone https://github.com/steamwood/ComfyUI-Goudan-AutoQueue.git
```

重启 ComfyUI。无额外依赖。示例工作流在 `example_workflows/`。
- `seedvr2_upscale_standalone_v2.json`：1.1.0 新版。左上「用户操作区」里只有路径、缩放设置、输出设置三个节点，其余都在「处理区（勿改）」。1.2.0 起读图节点上有「选择文件夹…」「选择图片…」按钮。
- `seedvr2_upscale_standalone.json`：旧版，仍然能用。

## 注意
- 一批没跑完时可以改提示词/模型/LoRA/轮数/文件夹再点运行，新的一整批会排在上一批后面，按顺序跑完。
- 内容完全没改又点了一次（误连点）会自动整次跳过，不会重复出图；想停下就清空队列。
- 节点上的「序号」保持 0。
- 1.2.9 起：一个工作流里有多个自动排队节点时，只有编号最小的那个负责排队，其他的在副本里自动关掉，不会互相翻倍；确认框的次数会乘上「批量次数」；提示词选择节点关掉 multiline 时按每行一条算。
- 1.2.9 起：还原记录.csv 被 Excel 占用时会重试，仍写不进就先写到「还原记录_待合并.csv」，下次能写时自动合并回去；以 = + - @ 开头的内容前面会加一个单引号，防止被 Excel 当成公式。
- 1.2.9 起：选择文件夹/图片按钮只接受本机直接访问，经过反向代理（带转发头）的请求一律拒绝。
- 一次排多少都可以（条数 × 轮数 几百、上千都行）。副本直接放进 ComfyUI 队列，排完会在右上角提示排了多少个。ComfyUI 的队列面板最多只显示 200 个排队任务，超过的部分看不到，但都在队列里，会照常按顺序执行，不会丢。
- 「文件名/文件夹（自动）」的日期用的是运行 ComfyUI 那台电脑的时间（格式同保存图像节点的 `%date:...%`：yyyy 年、MM 月、dd 日、hh 时、mm 分、ss 秒）。
- SeedVR2 续跑：`<原目录>/SeedVR2/` 里已经有「原文件名+后缀」的 png、jpg、jpeg 或 webp（包括 `_001` 这种重名编号）就算做完。中途换了输出格式也不会重做，自动排队的张数也会按剩下没做的算。
- 显存：长边越大越吃显存，大致和像素数成正比。3840 长边的像素数大约是 1920 长边的 4 倍。作者没有在 16GB 显卡上实测过上限，提示爆显存（OOM）就把长边或倍数调小，或者把 VAE 编码/解码的分块调小。
